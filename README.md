# Human Presence Detection and Dwell Time Analysis System

## Overview

This project detects people in videos using YOLOv5 and analyzes how long they remain visible.

## Features

- Person detection using YOLOv5
- Entry and exit event detection
- Dwell time calculation
- Presence statistics generation
- Annotated video output

## Technologies

- Python
- OpenCV
- PyTorch
- YOLOv5

## Output Metrics

- Visit Count
- Total Presence Time
- Average Stay Time
- Longest Stay Time
- Shortest Stay Time
